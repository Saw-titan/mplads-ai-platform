# Contributing to MPLADS AI Platform

Thank you for your interest in contributing to the MPLADS AI Platform!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/mplads-ai-platform.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes
6. Commit with descriptive messages
7. Push to your fork
8. Create a Pull Request

## Code Style

### Python (Backend)
- Follow PEP 8 guidelines
- Use type hints where possible
- Add docstrings to functions
- Maximum line length: 120 characters

### JavaScript/React (Frontend)
- Use ES6+ syntax
- Follow React best practices
- Use functional components with hooks
- Use meaningful variable names

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR
- Maintain test coverage above 80%

## Commit Messages

Follow conventional commits:
- `feat: Add new feature`
- `fix: Fix bug`
- `docs: Update documentation`
- `style: Code formatting`
- `refactor: Code refactoring`
- `test: Add tests`
- `chore: Maintenance tasks`

## Pull Request Process

1. Update the README.md with details of changes if needed
2. Update the documentation in `/docs` folder
3. The PR will be merged once you have approval from maintainers

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers
- Focus on constructive feedback
- Maintain professional communication

## Questions?

Open an issue with the `question` label or reach out to the maintainers.

Thank you for contributing! 🙏
